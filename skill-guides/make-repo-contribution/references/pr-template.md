# Pull request title

## Summary

Three or four sentences on what this pull request does.

## Background

The problem or feature, the issue it addresses (`Closes #NUMBER` when one exists), and any decision that is already settled.

## Changes

What changed, grouped by topic. Name the files that matter and the decision each group records.

## Testing

How the change was checked: commands the maintainer asked for, manual checks, and edge cases. Say which platforms were actually used.

## Additional notes

Breaking changes, migration steps, or review notes. Leave this section out when nothing here applies.
